## 阅读路径与设计判断

陌生工程师、研究者和领域人士应先看懂“它是什么”，再看到“如何工作”，最后找到“如何检查与运行”。沿用品牌句 **A place for expert work to take form.**；设计母题暂取 Evidence Editorial / Living Record，最终视觉由原站取证与实际产品资产共同裁定。

| 局部 | 内容与行为 | 依赖与缺项 |
|---|---|---|
| Identity / Hero | CourtWork、品牌句、实验性定位；一个可中断的来源/记录显露动作 | 复用 brand 几何与语义；可以做显式概念演示，不能演出已经完成的专业批准 |
| Actual surface | 首屏附近出现最终候选真实界面；清楚的图注、局部放大与回到全貌 | 合流后同 SHA、合成数据截图；未捕获前不放仿制截图 |
| One work path | 启动工作→查看工具/文件→处理实际存在的请求→检查结果；具体步骤按最终验收选择 | 优先可复现 Run 链；没有 Review/commit 纵切证据时不画完整闭环 |
| How it fits | UI / Host / Domain Core 分工；三段文字或一张小图，逐段链接契约 | 架构说明与实际支持范围分开；不把路线图写成特性网格 |
| Record / Access | 源码、启动说明、版本记录、采用的 Paper 与最新论文入口 | 下载按钮由实际发行产物决定；无包时显示源码/本地运行入口 |

发布页保留视觉表达的余地：大字阶、旁注、局部记录显露与有意的留白。正文与产品证据区恢复安静、可读的节奏。FIG / TRACE / REV 等标注只在真实对象适用时使用。对话中的 source→proposal→review→committed 仅保留为候选解释模型；目前 outcome 不等于 accepted work。

## 局部选型与取证入口

[reference-index.json](reference-index.json) 将首批参考拆为局部，而非网站收藏夹。全部初始为 `queued`，来自 Chat；没有本地截图和状态观察前，不得标记 visually_verified 或 adopted。本轮不背书原调研对站点现状的描述。

下一轮先抓 A0 的 rest / active / transition / mobile；重要动效补 reduced-motion、快速反向与中断。每次保存原站 URL、日期、viewport、实际 state、素材路径、失败情况与观察解释。只有 case study 的条目先从文章查原站，再抓原站；文章图片只能标为二手材料。若原站不可达，保留 blocked 原因并使用另一参考，不填虚构截图。

视觉决定至少对照：一个产品证据来源（Linear/Nova/Things/Zed）、一个 editorial 来源（Minard/Unlost）、一个语义 motion 来源（Exat）。候选风格不构成选用整个框架的理由。

## 技术准备裁取

拟采用独立的静态 `site/` 输出面，HTML/CSS + 少量原生 JS 是第一实现选项，是否需要生成器由实际双语/文档数量决定。本轮不安装依赖或创建空壳。现产品为原生 MJS，品牌是零依赖 SVG/Custom Element 包；无需因旧 React 参考迁栈。

- 页面仅消费经过挑选的公开内容、媒体与 brand 资产，不导入 server、store 或工作目录数据。
- 基础内容、锚点和源码入口在 JS 失败时仍可阅读。hover 的信息同样可由 focus/触摸获取。
- 品牌行为服从 [brand/CONTRACT](../../../../brand/CONTRACT.md)；不让动画结束生成业务成功。普通内容不循环运动。先静态布局，再局部状态过渡。
- 项目路径暂按 `/Courtwork/` 准备；实施时核实仓库 Pages 设置、域名和发布源。所有资源与站内链接须在带子路径的预览下检查，深链优先静态文件/锚点。
- Pages workflow 属于后续独立交付：显式站点输出目录、选定发布 ref、最小发布权限、构建产物与撤回路径。仓库现有 main 冻结，不默认向 main 写入或改变 Pages 发布源。
- 性能验收先记录首屏媒体尺寸与传输体积、layout shift、低速网络首帧；不预设 WebGL、全页 scroll 劫持或新的动画库。静态可读是增强失败后的基本路径。

|---|---|---|

| P4 发布接线 | Pages workflow、版本 manifest、回退步骤 | 对应发布安排的前置证据成立；站点 artifact 与候选一致；实际部署后检查公网 |
