Preview sends only `{expectedRevision, profileId, content}` to `POST /api/v5/runtime-control/preview-profile?sessionId=…`. Bind each response to Session, profile, exact submitted draft and observed config revision; changing any of these invalidates it. Old responses cannot overwrite a newer draft or imply that the newer text was checked. Retain typed source/Kit errors next to the source or affected reading. A preview is unsaved and does not select, execute, authorize, import or verify a provider.

Show the actual composition and effective `kit.status`, diagnostics/missing requirements, normalized pins, supported/unsupported/unchecked readings and UTF-8 bytes versus UTF-16 characters. Candidate text/hash is available only when returned; no partial text on refusal. Keep requirements, runtime compatibility and advisory allow/ask/deny readings separate. Technical hashes/details can use disclosure; scope and actionable failures remain near their action. A compiled preview is not provider readiness or permission approval.

Save uses the existing `PUT /api/v5/runtime-control?sessionId=…` operation `put`, whole-config `revision`, original resource metadata/scope and exact submitted text. Preview does not issue a save token. `save.available` is advisory, and PUT rechecks active-run/configuration conditions. Kit-refused but syntactically valid source can be saved by the Host; present that consequence explicitly rather than inventing an authorization rule or suggesting it will run. No automatic selection, retry, save-on-close or queued apply.

A CAS conflict retains the draft and offers fresh source/reading for deliberate reconciliation. A lost save response remains unknown until an explicit fresh source/hash/config read establishes current facts; a matching source confirms current saved bytes, not attribution of a particular request. A different source must not be overwritten automatically or labeled unchanged. Keep newer typing separate from the frozen submitted body. Active Run allows preview but blocks Save under the actual Host freeze; completion unlocks only through fresh owner facts.

Return from Settings preserves Composer text, caret/materials and Session identity. Preserve editor drafts across the in-app navigation covered by this slice, keyed to the correct source and Chat; do not promise reload persistence without implementing its own explicit storage contract.
