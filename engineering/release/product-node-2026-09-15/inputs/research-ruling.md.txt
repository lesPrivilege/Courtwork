| 官方来源 | 可消费结论 | 不从该来源推出什么 |

| [Anthropic Context Engineering](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)，2025-09-29 | 引用、按需取用和持久笔记可与有限上下文配合 | 不证明任意摘要可靠，不取消来源与任务适用性判断 |
| [A2UI Actions](https://a2ui.org/concepts/actions/) 与[组件目录](https://a2ui.org/concepts/components/) | 可信目录、声明式数据、动作返回、局部视图与后端校验分开；数据同步还需要接收方隔离 | 不指定全量采用 A2UI，不把 UI 检查当正式接受；v1.0 在页面导航中仍为 candidate |
| [VS Code Commands](https://code.visualstudio.com/api/extension-guides/command) | 一个命令可出现在不同位置，菜单 when 与命令 enablement 分开 | 不把出现/禁用状态当权限系统，不为右键菜单另造业务命令 |
| [OpenAI Agents API events/items](https://developers.openai.com/api/docs/guides/agents-api/sessions/events) | Exa 返回事件与持久 items 区分、断流后按记录恢复、turn 结束不保证每个工具成功 | 直接 web fetch 本轮 cache miss；接入前须再固定官方 SDK/协议与运行证据，不据此宣称现有 adapter 已兼容 |

A2UI 的全量 surface data model 同步需要显式接收方隔离，这与 CW 按需披露原则有关；“使用成熟组件”不会自动解决出站数据治理。以上机制服务现有原生前端与 owner 接缝，不形成新的依赖安装清单。
