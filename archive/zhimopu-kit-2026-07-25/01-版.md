## 二、色律

1. 声部止于两部：朱、雌黄。二色只承语义，不承装饰；主操作用墨（刊例第三十条）。
2. 朱司人裁与交互：链接、焦点环、批点、校勘记同出一声。雌黄司校改：错误、警示、涂乙。据：朱批、黄涂皆校雠旧法（「信口雌黄」之雌黄即涂改之色）。
3. 各纸各自复核对比度并著录于宗文件（刊例第五条）：文墨对纸宜 ≥7:1，淡墨与二声部须 ≥4.5:1。
4. **二声部不同族**。墨入金族之纸（磁青），雌黄须离金而就柠（雌黄本色即柠）；二声部与墨、二声部相互，须色相可辨。
4. **影零处**。纸面无投影；层级以界行、纸三层（纸→副纸→浮台）与器面四阶（六）行之。此为本谱家法，较刊例「影一处而止」更严；工作台扩编之唯一影见十三。
5. 灰字不压彩底；tint 不作行 / 卡底色。
6. 纸墨之对比取两极（近白 / 深暗），中间调唯与界与淡墨；纸弱化己身，不以色温拠风格。

## 三、界行

主界一档司结构（版框、编界、牌记框），次界一档司行列，两档而止（刊例第廿八条）。

**界不取墨**（v0.3 家法，入藏件 rule-ink 实证）：两档界色皆为纸墨之间的轻调，主界略重于次界；墨唯承字与实底器物（主按钮、当前项）。黑框围面即古质过重，不得。主界宽默 2px。文武边框（外粗内细双线）唯版框与牌记可用，他处不得；其内线宽独立为 `--kuang-nei-w`，古印 1px，今印 0——框退单线而 markup 不变。界宽入底本，不散落字面量。

## 四、字四轨与档

题、文、器、数各轨各值；相邻题级档差须 ≥1.25；伪粗不施（`font-synthesis: none`）。汉文正文行长宜 32–38 字，拉丁文 65–75ch，混排从主文种。

## 六、器面四阶（馒版之阶）

纸三层只管面，不管器；器物自有四阶：`--qi-mian`（常）→ `--qi-fu`（悬）→ `--qi-an`（按）→ `--qi-xuan`（选）。

**据**：套印与馒版——多版分印，每版一次印色，深浅成阶而不靠投影（存目已著：套印本·馒版·拱花）。今之平面设计以色阶代浮雕，正同一理；暗面尤须如此（暗不能再暗，只能递亮）。

**律**：

1. 底纸居一极（最浅或最深），阶向反方递进：浅纸阶渐深，暗纸阶渐浅。暗面之层级以阶升亮而得，非以影与光。
2. 四阶**只承器物**（按钮、输入、行、签、开关），不得作面底与卡底——否则卡中卡从此而生。
3. 一器一阶，不得跳阶（常→按 而无悬）；阶差须可辨而不得宏，相邻阶之亮差宜 2–4%。
4. 主按钮不入四阶：墨底纸字，一书唯此一实底器（最高强调）；余器皆从阶。
5. 阶与界共作：器既取阶底，仍可取次界框；影仍零处。
6. **禁阶别立**：`--qi-jin` 不入四阶之递（禁非一种交互）。禁器取禁阶底、淡墨字、框不变，且须另告何以不可用；淡墨不兼司禁态（一槽一司）。

## 六乙、影抄之纸（浮层之材）

纸三层之外另有一层：`--zhi-ying`（半透底色）与 `--ying-mo`（模糊半径），唯予**浮于内容之上的导航层**。

理路取于现行之法：浮层需与内容分而不断，故以透代界。名取影抄，因职分相协（薄纸覆底本而透见其字，见底而不失字）；止于命名，不再深推。

**律**：

1. 影抄唯予浮层（工具条、粘性头、底页、菜单、浮钮）；不得予内容层之表、卡、列，不得作全屏底。
2. 一面一影抄，不得影抄叠影抄（叠则字失）。
3. 其下内容须可滚过；交界以渐隐（滚动边缘）代硬线，唯浮层实与内容相接之处施之。
4. 字压影抄者加重一档、微开字疏，且须复核压后对比度 ≥4.5:1。
5. **底为实、透为增**：默认实色，透与模为增益；`prefers-reduced-transparency` 尚未入 Baseline，不得以透为基线。
6. 影抄不解影零处之禁：影仍零，透非影。

## 七、动静

**动分二类**：自动（页面自作之动）与随手（人手在场之动），二者律异，不得混治。

**自动**：数据与表格之区绝对静止。动为仪式：一书唯入场一次编排；属性限 transform / opacity；语义状态（含换纸）零时硬切；`prefers-reduced-motion` 为公法义务（刊例第卅二条）。

### 七乙、随手之动

随手非装饰，乃反馈本身，故不受自动之禁。理路取于现行流体界面之学；其二态之分与装帧相协（卷轴推之则续行而有惯；经折翻之则一折一定），止于分类，不再深推。

**律**：

1. 按下即应，不待释手；反馈贯于全程，非唯终了一现。
2. 随手一比一，守捉点之偏（不得一捉即跳至元素中心）。
3. 动可随时截、可反；起值取**现值**（屏上实值）而非目标值；转场中不得锁输入。
4. 释手交速（以释手之速作弹簧初速）；反向时融速而不硬切。
5. 以势投程而后吸附（指数衰减 0.998），非就近吸附。
6. 逾界则渐阻（皮筋，常数 0.55），非硬止。
7. 弹律二档：`--tan-chang`（1 0.35，无过冲）为常；`--tan-shi`（0.8 0.3）唯承有势之释手。二维之动分 X、Y 两弹，不得合为一距。
8. 随手不受「零时硬切」之限；然语义状态之切仍硬切，数据之区仍不得自动。
9. `prefers-reduced-motion` 下随手仍随手（其为反馈），惟去过冲与投程，改就近吸附。
10. 凡随手必备单指替代（见十四）。

## 八、行款著录语

每宗、每面须能一句著录，式为：

> 文行 N 字（或 N ch），档差 ≥1.25，界主次两档，圭角 X，影零处，彩二声部（朱、雌黄），数据静止，自动唯入场一次，随手从弹律，靶不下二十四，印法古/今。

著录语入宗文件与页脚，作对校基准（刊例第廿七条）。

## 九、换宗与根值

**换宗之律**：换宗即换纸：只在底本层换 tokens 文件或 `data-zong` 值；组件、版式、markup 零分支。任一宗下出现分支者，以私自分叉论（刊例第四、五条）。

**根值唯一**：只有默认纸（月白）与古印得写 `:root`；他纸、他印唯应属性选择子。非默认纸写 `:root` 即争根，包外之元素将继承错纸（本谱已见一例，入校勘记）。退役之纸不得再被页面加载（存档即止）。

## 十、印法

纸外第二轴：**古印 / 今印**，`data-yin` 切换，值全在底本层（`yinfa.tokens.css`，须最后加载），markup 零分支。

- 今印所改：框内线归零（文武退单线）、主界收细、题文转黑体。
- 今印所不改：语义槽、声部、记号之义、牌记、著录语、圈点；**行距与字疏亦不入印法**（归纸）——暗纸光晕补正不得被印法销去，否则牌记著录语即与实排不符（校勘记 v0.6）。
- 据：取法不取貌之彻底化——扁平本身即一次陌生化转化。**风险特著**：今印近分布中位，其陌生化承重全在法；牌记、著录语、圈点为可指认签名，须存，删之即滑回坊刻。

## 十一、著录词

牌记与版本记录用词，出刻本、写本之谱系：

- **版本词**：初刻＝初版；重刻＝改版重构；覆刻＝忠实移植（跨栈重现）；影刻＝登记副本，署非权威；递修＝增量修订，一系累印；百衲＝多源拼合，须著各源；三朝＝跨代递修，非病。
- **稿本状态**：手稿＝工作稿；清稿＝净本待雠；抄本＝人工转录；過錄＝批注转录。
- **書品**（审书状产出）：上品＝不刊应记全过；中品＝应记项留档；下品＝不刊有犯，不得行世。

## 十二、档位

回流自入藏件（Courtwork 评估板）：**视觉激进度与裁决距离成反比**。

- **激进档**：展示与叙事面，距裁决最远，表达自由最大；动效与字形例外只得在此档申请。
- **中间档**：导航与 chrome，可有作者性而须克制，不得抢裁决层。
- **克制档**：数据与裁决工作面，版式从数据生长，零新装饰，数据区绝对静止。

许可**不跨档继承**：激进档探得之形，须过克制审计方可下迁。记号准入五问之四即系于此。

## 十三、工作台扩编（可选件）

文档面二声部已足；产品工作台需状态声部时，引入 `02-宗谱/gongzuotai.tokens.css`（实证值自入藏件回流），律如下：

- 扩编槽：危 `--wei`、慎 `--shen`、成 `--cheng`、交互 `--jiao`、中性 `--zhong`（各配 `-di` 淡底）、选中 `--xuan`、唯一影 `--ying-tai`。
- 扩编在场时分轨：**记号色古，交互色今**——朱归裁定印记，交互从 `--jiao`；雌黄与 `--shen` 同声不双用。
- tint（`-di` 底）只上小块提示，不作行 / 卡底；灰字不压彩底；数据容器取浮台＋界线。
- `--ying-tai` 为全书唯一投影，只上浮台级容器，用则应记（破影零处家法须书面理由）。
- 暗纸取值未著，各暗面自复算对比度（刊例第五条）。

## 十四、手位与靶

此不属风格之选，乃公法下限（与 `prefers-reduced-motion` 同档，各地法规多挂 WCAG 2.2 AA）。

1. 凡可点之靶 ≥ `--ba-xiao`（24×24 CSS px，AA 下限）；主操作与触屏之靶宜 ≥ `--ba-zhu`（44×44）。图标器以 padding 达靶，不以放大图形达靶。
2. 小靶以间距救之：24px 径之圆居各靶中而不相交。
3. 行内文中之链接不在此限（其尺受行高所制）。
4. 凡拖拽皮备单指替代：滑轨可点、上下移按钮、「移至…」菜单、前后翻钮；惟以路径为内容者（手绘、签名）为例外。替代不得唇一句而无实路。
5. 键盘路径与焦点环不代单指替代（触屏用户本无键盘）。

## 十五、器上文之语

取材、用色、视觉元素取于版本之学；**器上文取现代平易汉语**。二者不相涉。

- 古典词汇只行于**谱内**：槽名、记号名、文档、牌记、著录语、校勘记。此为设计系统自用之名，与用户无关。
- 用户所见之字——按钮、菜单、字段名、错误文案、空态、引导——一律现代汉语：直、短、具体。该写「保存」就不写「写定」，该写「删除」就不写「黜落」。
