# SITE-MOTION-NATURAL-GROWTH-1 · runtime evidence

This directory is the independent C runtime proof for the Pages `record → seal` motion batch. It is
derived from the N2 capture shape, but its active surface is the current Pages DOM rather than the
retired schema demonstration.

`capture.mjs` records:

- `light/dark × 375/768/1180/1280/1440/1600` reduced-motion overflow and broken-image probes;
- full-page JS-off dark output at 1280px;
- no-preference animation-name census with `typer-develop` as the only CSS animation, and a reduced
  census allowing only the existing `ghosty-reduced-fade` exception;
- Evidence and seal `before/mid/settled` frames. The mid frame pauses the actual CSS transition and
  sets its Web Animations timeline to the midpoint before taking the screenshot;
- a dark 1280px data double-sample covering fixture counts and PM projection nodes.

`assert-reduced-motion.mjs` is the focused reduced runtime gate. It checks computed animation and
transition state for Typer, Ghosty, Evidence markers/connectors, and the seal, then compares protected
data text, bounding boxes, transforms, animation names, and transition durations across samples.

`REPORT.json` is generated by the capture command and records target SHA, allowed actions, protected
selectors, frames, matrix probes, transition timelines, data-static result, and failures.
