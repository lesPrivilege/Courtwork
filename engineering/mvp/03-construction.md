# MVP 条件施工工单

遵守 [共用规则](README.md)。以下描述交付契约，不预选框架或源码布局；须通过 MVP-12 才能派发。实验代码是否复用需审查，不能把 spike 直接视为产品模块。

## MVP-13 最小宿主与工程基线

依赖：MVP-12。

工作：按裁决建立实现工程、锁依赖、类型/构建检查、测试入口、本地启动/关闭、配置与健康状态。限定本地连接来源，明确进程间认证和数据目录。

产物：可复现工程基线、开发运行说明、兼容版本表与架构映射。

验收：新环境按说明启动；缺配置友好失败；未知客户端不能调用可信 Review；无秘钥入包/日志。只创建必要模块，不搭通用插件平台或桌面壳。

## MVP-14 Runtime Adapter 产品化

依赖：MVP-13。

工作：落实 07 验证过的启动/提交/观察/取消/pending/snapshot 能力、关联 ID 和错误分类；将 Run 生命周期与 Matter 分开。

产物：适配器、契约测试、上游版本差异说明。

验收：协议乱序/重复、断线、取消迟到、过期回复不误写正式状态；无 durable replay 时用 snapshot 明确恢复。更换上游不能让 GUI 直接依赖私有事件。

## MVP-15 Repository 与唯一提交入口

依赖：MVP-13。

工作：落实 08 的存储裁决、schema 版本、Candidate/Decision、幂等/CAS、验证后重检、原子审计/状态/产物/义务、补偿与恢复。

产物：提交 API、迁移/备份接口、Core 不变量回归证据。

验收：同键重试稳定、异载荷拒绝、并发仅一个成功、丢 ack 可查回；拒绝/修订不提升候选为有效成果；失败无半份有效产物。LLM 不能指定可信 actor。

## MVP-16 文本输入、Artifact 与 Evidence

依赖：MVP-13、MVP-15。

工作：实现限定文本格式的导入与版本、读取状态、不可变成果、来源锚点、完整性检查和原文定位；复制/下载若开放须带明确版本。

产物：输入与成果服务、Evidence 解析/定位契约、失败说明。

验收：空文件、超限、非法编码、不支持格式、移除或替换来源不会变成 ready；错版/缺失证据阻断相应提交；hash 不声称来源真实。无静默截断后假装完整读取。

## MVP-17 工具能力、凭证与预算边界

依赖：MVP-13、MVP-14、MVP-15。

工作：注册只读批准输入与提议工具，关闭任意 shell/外写；凭证由 Host 管理；限制调用/时间/输入大小。permission pending 与 Review 走不同授权路径。

产物：实际能力清单、边界配置、否定测试与凭证处理说明。

验收：恶意来源要求读任意路径、写 DB、取密钥或伪造接受均不能成功；拒绝/超时无默认放行，预算在行动前检查。无法阻止绕过就收窄宿主能力，不能以 UI 隐藏按钮交付。

## MVP-18 Context 投影与静态 Extension

依赖：MVP-14、MVP-15、MVP-16。

工作：从当前状态、有效 Artifact、Evidence 和义务形成确定性输入；固定一个可选预设及版本/能力，Run 绑定配置。索引如需要仅作为可重建缓存。

产物：投影器、版本化预设、Context 检查记录。

验收：零 Extension 可运行，缺失/不兼容预设有解释；换 Session 或清索引不丢正式状态；旧配置不悄然改变既有 Run。上下文裁剪显式保护约束和义务，不复制整个聊天冒充连续性。

## MVP-19 GUI 基础与输入闭环

依赖：MVP-13、MVP-16、MVP-18。

工作：实现选定 Design 基础、Matter 列表/切换、配置、Composer、附件和基础帮助，覆盖 UI01—05、18；支持工作间持久草稿，运行中禁发但保留编辑作为首版默认候选行为。

产物：基础 GUI、真实输入服务连接、组件状态及键盘说明。

验收：配置错误、发送失败、附件失败都保留输入；快速切换不串内容；中文 IME 不误提交；看得出哪些附件进入 Run。若改用排队，先补队列语义和验收，不能临时增加假 steer。

## MVP-20 GUI 执行与恢复面

依赖：MVP-14、MVP-17、MVP-19。

工作：连接流式输出、工具摘要、pending、停止、断线恢复和分步错误，覆盖 UI06—13；长输出滚动/选择保持，明确 Run 与 request 身份。

产物：真实 Runtime 工作面、错误与恢复文案、状态映射。

验收：停止请求/停止中/已停/未知可区分；重连重取状态，重复/跨工作回答被拒；限流与部分失败不触发危险全量重试；追加 token 不抢焦点或逐个读屏播报。

## MVP-21 GUI 成果与 Review 面

依赖：MVP-15、MVP-16、MVP-19。

工作：连接候选/有效/旧版本、Evidence 回跳、差异、接受/退回/修订、义务与继续工作，覆盖 UI14—17。

产物：可信 Review UI/API 集成、结果和冲突表示。

验收：检查未完不冒充通过；提交中不乐观显示接受；旧页面产生可恢复冲突；回跳返回阅读位置；Run end 不清除未完义务，模型输出不直接成为有效成果。

## MVP-22 单任务真实纵向闭环

依赖：MVP-17、MVP-18、MVP-20、MVP-21。

工作：在冻结环境和预算内以真实 provider 执行候选→退回→修订→接受→重启→新 Run 继续；用同一套样本关联 GUI、Adapter、Core 与 Evidence。

产物：D4/RD-003 真实切片记录、输入/配置/事件/版本索引、与模拟结果差异。

验收：六路径在真实集成中可走通；有效成果和义务不靠聊天重放恢复；不混用 fixtures 填补实际失败。专业内容质量与工程完成分开报告；关键失败回开责任工单。
