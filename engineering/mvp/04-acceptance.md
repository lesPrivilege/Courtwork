# MVP 验收与交接工单

遵守 [共用规则](README.md)。本组验证已施工结果；文档检查不能代替这些验收。

## MVP-23 集成故障与恢复验收

依赖：MVP-22。

工作：在真实集成上复验 RD-001/002 的风险边界：进程 kill、丢 ack、双提交、取消迟到、断线 pending、工具拒绝、预算耗尽、凭证/路径绕过、缺来源和过期候选。

产物：故障点/期望/实际/恢复动作矩阵、最小复现和缺陷归属；可控故障注入与真实 provider 分栏。

验收：不丢正式状态、不误接受、不跨 Matter、未知效果不自动重试。所有阻断缺陷修复后复验受影响路径；无证据的异常不得标通过。日志足以定位 request/version 且不暴露凭证。

## MVP-24 GUI 完成面与 Craft 验收

依赖：MVP-22。

工作：独立演练六路径及 UI01—18；核对长文、中文 IME、键盘/焦点、读屏摘要、缩放、窄窗口、reduced motion 和错误恢复。按真实观察调整排版、tokens 和动效。

产物：逐项适用性/实际证据、设计偏差与修复记录、指定环境性能测量；阈值在测量前依任务冻结。

验收：停止不可达、丢草稿、错误无出口、证据错版、误认已接受或键盘阻断均不得豁免。陌生化机制保留须有工作价值；删装饰是允许的完成方式。无真实体验检查不得以截图漂亮交付。

## MVP-25 本地交付与维护手册

依赖：MVP-23、MVP-24。

工作：验证干净环境安装/启动/关闭、固定依赖与许可、配置和数据位置、备份恢复；演练一次 schema 变化及旧程序遇新 schema 的安全拒绝。整理上游兼容矩阵、升级/替换触发器和待反馈问题草稿。

产物：本地运行包/说明、维护 runbook、版本与证据清单、已知限制、手动生态复查 Assignment 模板。

验收：另一位执行者可依说明恢复已接受成果与义务；不含凭证和私密样本；回退不能静默破坏数据。明确恢复兼容范围，不承诺任意 downgrade。无需发布、外发 issue 或设置自动监控；这些另行授权。

## MVP-26 MVP 接受与下一轮裁决

依赖：MVP-25。

工作：Reviewer 对照 01 范围、Core 不变量和 GUI 完成面检查证据，由用户接受、缩小或退回；更新 current、RD、工程/Design 裁决与 roadmap 的实际位置。

产物：验收结论、未完义务及责任、下一轮最小 Assignment；每项声称通过可回到执行证据。

验收：所有范围内硬门槛满足才称本地个人 MVP 完成；未做多用户、跨宿主、外写、长期升级不得外推。只提议 R4/R5 后续，不自动启动第二场景或扩大 agent 权限。
