# Change record · working-location entry

2026-09-21 · Claude (Opus 5), author. Written before any product file changed.
Ruling: [composer-entry-review-20260921](../composer-entry-review-20260921/README.md).
Base: integrated main `3bf1e0b`, tree `claude-work-location-20260921`.

| Field | Entry |
|---|---|
| Task / scope | Replace the separate *Connect folder* chip and composer *Project* button with one entry in the context band. Its collapsed label is *Choose work location* or the chosen project and folder names; expanded, it is titled *Work location*. Inside, Project and Folder stay separately labelled. Flatten the nested cards and bring glyphs and text into proportion. |
| Owner facts | Project is the organisation fact. A Chat's project is fixed at creation, because the Host offers rename, not move. Folder is the repository binding (Host). The private candidate and file access keep their existing owners. The preparation marker and its reconciliation stay in `home-preparation.mjs`. |
| Surfaces changed | `workspace-card.mjs` (card content, now titled Work location), `app.mjs` (`renderContextStrip`, `renderHomeComposerContext`, the Home project chooser and wiring, popover focus return), `index.html` (composer Project button and project popover removed), `styles.css` (band, entry, flattened panel). |
| Affected UX rules | UX-01 (one entry; no duplicate chooser vocabulary). UX-02 (the reason a location cannot change stays at its control; the full path is in the panel). UX-03 (the entry is a Button opening a dialog-like popover; project choices are pressed buttons, as now). UX-06 (recovery routes unchanged). UX-07 (the two facts are grouped by spacing and a divider rather than two bordered cards). UX-09 (a shallow band; empty states take one line). |
| Nearest precedents | The existing context strip (`renderContextStrip`, the RD-006 comment block). The Home project popover (`home-project-popover`, `workspace-option`, `aria-pressed`). The accepted 06b Workspace card with its preparation-recovery branches (`b3f3fd7`). `FOCUS_CHAIN` in the same card. Icon slots of 16/20 px and 32/44 px targets from `icon-controls.md`. Design Scout marks the composer as settled (FE-03 / CC-W) with S12 as the product precedent. The user's Codex screenshot is a visual reference only. |
| Kept relationships | The Host bind / preparation / candidate commands and their identities. PA-R1 correction path, PA-R2 locks, PA-R3 marker retirement. Check status and Continue preparing stay reachable under uncertainty. Draft text, materials and permission select stay where they are. The band is shown on Home and in a Chat with no Run, as before. `#workspace-chip` keeps its id. |
| Intentional changes | The composer loses the Project button, and the project choice moves into the panel. The band entry gets the folder glyph (`workspace.object`, multi-purpose). Local and Branch stay text-only. The entry is never disabled: when a location cannot change, the panel says why. Escape and Close return focus to the entry. The entry node is stable across renders. The full path appears as a secondary line under the folder name rather than in a narrow value column. Panel sections lose their inner border and background. Row glyphs go from 18 to 16 px to fit the icon slot scale. The entry hit area is 32 px on desktop and 44 px in the narrow layout. |
| New terms / primitives | UI labels only: *Work location*, *Choose work location*. No persistent object, route, schema, event, token, icon or dependency. |
| Exceptions / gaps | The ruling's device and branch glyphs are not available. `git-branch` is registered single-purpose for Fork (`message.fork`), and no device glyph exists in the shipped Lucide subset. Admitting either needs a product-semantics entry, which is outside this slice. |
| Before measurements | [before/measurements.json](before/measurements.json). Band chip 22.7 px high (below the 32/44 target convention). Escape from the Workspace panel leaves focus on `<body>` at all four viewports. The full path wraps one character per line in the value column. The prepared panel is taller than a 900 px viewport. |
