## Selected finite migration candidate

**Runtime Settings block rhythm, styles only.** This is the one bounded candidate returned for parent disposition. Scope the write lease to app/web/styles.css selectors for the Runtime Settings block containers and their titles, using the existing mount IDs/data-wk11-mount surfaces in app/web/index.html:503-624; do not edit Settings navigation, settings-view.mjs, runtime-management-view.mjs, or 06d files.

The source cause is concrete: generic .settings-block currently uses 8px top padding, 20px bottom padding and 40px bottom margin (styles.css:5337-5343), while .settings-block-title adds 12px top margin and 4px bottom margin (styles.css:5351-5355). In the rendered Runtime Settings sample, the border-to-next-heading gap therefore combines the block tail with the next title’s top rhythm; parent measured a 60px gap. The candidate should first measure the Runtime mount subset at 1280/390 CSS px, fine/coarse pointer, normal/large text, long status/reason and loading/error/unknown states, then select the smallest scoped selector adjustment that preserves row separators, readable help, overflow, focus rings and 44px narrow/coarse controls. The existing computed reference is [01-settings-desktop.json](../01-settings-desktop.json); it records viewport, DPR, pointer and text-scale assumptions. Counterexamples are long runtime names/status text, wrapped command reasons, focused Back/action controls, pending/unknown/error notices and browser text-spacing overrides. No exact replacement value is adopted by this source map.
