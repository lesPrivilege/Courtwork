# Evidence packet index

This directory holds dated, scoped evidence packets for CourtWork. A packet README is the owner of its commands, exact source/receipt details, scope, failures and `not_run` boundaries. This index is only a directory map; it is not a second status ledger. The current product status remains [`engineering/current.md`](../engineering/current.md), and the relevant contract remains the authority for each behavior.

Dates below are taken from the packet directory name when present. `not encoded` means this index does not infer a date from file contents. Classification describes the packet's evidence surface; it does not by itself mean implementation, acceptance, publication or deployment.
