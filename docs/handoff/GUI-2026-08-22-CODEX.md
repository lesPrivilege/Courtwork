## 五、门命令与既有判例

`apps/desktop` 下：
`pnpm lint:design-md`、`lint:neutral`、`lint:rp211`、`lint:elevation`、`lint:graph`、
`lint:typography`、`lint:layout-converge`、`lint:ui-surface`、`lint:voice`、`lint:work-agent-gui`、
`lint:icons`（HIERARCHY 票另需，证明零新图标）。
`site` 下：`pnpm site:guard`。仓根：`pnpm lint`、`pnpm -r build`、`pnpm test`、`git diff --check`。

判例，都是本仓栽过的：

- **跨包测试前必须先 `pnpm -r build`**，否则 stale dist 给假红或假绿。
- **Playwright 走 `pnpm test:e2e`，不要用 `npx playwright test`**——后者绕过前置静态门链。
- **命令末尾不要接 `| tail`**，zsh 下吃掉退出码造成假绿。
- **mutation 零红要如实登记为无效变异并换靶**；零红也可能是补丁没生效，先自查命中。
- **跑完门之后又编辑了文件，必须重跑相关门**。提交前最后一个动作是跑门。
- **截图前确认测试页已写 `data-theme`**，否则深宗帧失真（`GUI-LEAD-WHITE-1` 已栽一次）。
