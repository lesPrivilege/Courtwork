## Result and owners

- Chatspace Context is a ring-only button between model/effort and Send (or Stop). It opens the retained request estimate, serialized character count and declared window. These remain separate facts; the ring has no capacity arc or percentage.
- Latest Run feedback is a persistent activity row in the message stream, with the waveform at the left and a short phrase. First-level TPS, missing-rate text and chevron are absent; the glyph opens the measurement card. Historical Run inspection and formal decision receipts retain their contracts.
- Working/Thinking phrases rotate every 3.5 seconds. Exact Run tool events select reading, writing, searching or general tools; assistant text deltas select composing; compaction/retry notices select those phases. Multiple open tools are tracked by call ID. Pending cancellation freezes decoration; only a host terminal fact says Cancelled. Waiting, failure, lost connection, hidden surfaces and reduced motion stop the clock. The app-level Always reduce preference is also observed.
- Attention consumes the same activity projection without measurement controls. Existing memory/runtime disclosure remains its own surface.
- Two native auto-popover cards reuse shared anchoring, solid raised material, focus and 180/120ms disclosure. Keyboard opening is instant, Escape returns focus, outside dismissal works. Snapshot data stays stable while reading; Refresh only rereads retained events. Session/Run changes close the card. Inspect run uses the existing target.
- No backend schema, provider token clock, dependency or authority changed. Missing decode TPS stays missing in details. Host timing is not provider TTFT. Specific prose such as Adding targeted tests is not promoted into an asserted progress fact.
