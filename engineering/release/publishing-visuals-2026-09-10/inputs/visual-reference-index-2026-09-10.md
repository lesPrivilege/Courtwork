## 主张摘要

1. 成熟影像 Skill 应当作视觉编译器消费；输入 IR 由 CW / SE 自己定义。链路：语义 → visual brief / IR → visual grammar → renderer（SVG / procedural / image）→ visual QA。
2. 取自 anthropic-style-diagram 的边界：调用方负责 geometry + meaning，renderer 负责 theme / colour / crop / export。
3. 六个语义 → 视觉抽象的配对（SE 三层、Store→Govern→Retrieve→Compile、Matter 工作空间、Attention、Spark、Experts + 可替换 Runtime）。
4. 首批五张原创母题：Matter as durable workspace；Store→Govern→Retrieve→Compile；Attention emerging from ambient work；One Matter / multiple Experts / replaceable Runtime；Evidence→Candidate→Human Decision→durable state。另配真实截图。
5. 不以 “Anthropic style” 命名进入长期规范，熔炼为自有 grammar（editorial-paper、governed-system、evidence-plate、process-cutaway、spatial-work、ambient-computation）。
6. 建议目录 `site/visuals/{semantics,briefs,accepted,generated,manifests}` 与 `engineering/design/{visual-grammar,visual-semantic-registry}.md`；semantic registry 是关键（每个概念写 canonical meaning / allowed motifs / avoid）。
