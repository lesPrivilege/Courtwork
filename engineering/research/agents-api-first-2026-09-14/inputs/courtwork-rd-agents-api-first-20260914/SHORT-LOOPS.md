# 近期线 · Dogfooding 与真实测试一起推进

2026-09-14 · 候选施工计划；本地已有 writer 与当前回执优先。本文不宣告任何测试已运行。

## 1. 两种 dogfooding 必须分账

**开发者 Agent 使用 CourtWork GUI**：本地 Codex 读仓库、修改代码，接用户授权的真实浏览器，观察功能、报错和视觉结果。这证明研发闭环与产品交互可检验。

**CourtWork 内的 Agent 完成工作**：用户在 CW 发任务，CW 自己的 runtime 与工具实际读、改、测，保存产物、检查结果、人审和续接。这才证明产品暴露了相应工作能力。

外部 Codex 通过终端把测试跑通，不能算 CW 内部 Agent 已拥有 test runner。开发者在浏览器点通按钮，不能算产品已具备 computer-use extension。相同任务可以留下两类证据，但分别说明执行主体、入口与事实 owner。

## 2. 近期最小任务族

| 小 loop | 想达到的效果 | GUI 与后端必须共同出现的结果 | 主要反例 |
|---|---|---|---|
| 现有 Pi coding | 产品自己改一处并检查结果 | 精确文件/diff、工具实际执行、退出/检查结果、可再打开 | Agent 声称测过但无执行；失败被 completed 遮掉 |
| 配置真实生效 | 人更改模型或已支持资源后知道何时生效 | 当前草稿/保存配置/历史 Run binding 各自可辨 | 旧回执清掉新草稿；变更污染旧 Run |
| 材料交接 | 上传后不是在 Finder 中重新找文件 | 精确保留版本、引用、后续 assignment/Work 消费入口 | 同名文件替换；撤权后旧引用继续读 |
| Agents API 首接 | 另一执行器进入同一 GUI | session/turn/call 关联、真实 function 往返、停止和恢复 | 断线重复执行；idle 误判成功 |
| 正式工作与重开 | 实际人审有明确后果，下一次可继续 | Core Decision/Artifact、版本依据、未决、新 Session | 工具 allow 被算 accept；fixture 代签人审 |

原 G1–G5 和 DF-04 等的覆盖由本地逐项映射，本表不是第二份 gate。已有有效实现不因新任务标题再次施工。用户正在进行的其他 dogfooding 不暂停等待长期研究。

## 3. 给 Codex 真实 Web UI 的方式

先确认具体受测 build、origin、独立 data directory、浏览器 profile、数据种类与授权范围。页面要暴露源码身份或可核对的 build manifest，避免浏览器连着旧 Host，代码却在另一 worktree。

Codex 先用原入口观察，再作一个局部修改，运行足够定位失败的测试，回到同一用户路径验证。真实产品状态通过 UI 或受信 API产生；为构造 fixture 可用合法 seed，但不能直接改 DB/DOM/localStorage 冒充用户路径已经成功。

任意可复现 bug 先描述用户结果和失守不变量，再下沉到正确层级的回归。截图证明几何和视觉，Host/数据库回执证明保存与状态，模型产物与检查证明能力；三者不互相代替。

### 浏览器工具的研究建议

优先继续使用本地已配置且可用的浏览器工具。本次官方 Playwright 文档区分：CLI 面向 coding agent 的命令/skill 路径，MCP 面向需要持续页面结构的交互循环。[S18–S19] 据此登记选型，而不是自动加依赖。

需要可重复浏览器行为时，将适合的探索沉淀到现有测试或后续明确采用的 Playwright Test；`playwright-cli` 不是测试 runner。真实头部浏览器供人观察，独立 profile 防止把日常账号、其他标签页和敏感数据交给 Agent。多人/多 Agent 不共享活动 profile。

“让 Codex 自己测试”不等于只读 accessibility tree。交互用语义定位；布局、遮挡、字体、留白、缩放和焦点必须看实际页面。必要时保留实际 screenshot/trace，不要求每个点击一张全屏截图，也不预承诺 token 节省比例。

## 4. 本地工单的最小完成定义

每单只冻结一个主要用户结果和一类风险边界。交付同时包含实现、合同差异、真实交互路径、对应失败/恢复证据，以及当前支持边界。后端 API 与 UI 各自做完但未合流，只能叫半片。

完成一个局部节点不强制跑所有历史测试；采用 engineering/verification.md 的风险选择。不能用精简测试为借口省掉本片承重的 SDK、HTTP、持久化或浏览器接缝。

真实 API 凭据由用户在可信入口配置；本包不默认运行付费模型。申请有界实际任务预算，超时/取消有独立证据；usage 未知保持未知。没有支持的硬费用上限时，不能把本地软预算宣传为供应商收费保证。

## 5. 组合与停点

每片单独可回退，不切换共享工作树、不覆盖其他作者。共享 service/store/UI 文件由明确 writer 串行修改。测试/文档可有界并行，最终组合后复核同一 build 的完整路径。

作者可以实现并检查，不能自称独立接受；非作者复核实际 source 与原始结果。正式人审由真实人决定。API 新 lane 不通过时，原 Pi 不受影响；未知远端效果先核对，不用重试掩盖。

近期停止条件不是“没有任何积压”，而是已选能力完成从用户动作到真实结果的闭环，并准确回写 current。长期研究只把有明确消费者的小片送入后续队列。
