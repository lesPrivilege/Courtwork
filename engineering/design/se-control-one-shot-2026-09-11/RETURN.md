# 独立 Design 返回合同

请一次返回可裁决、可复现的系统方案，覆盖 DG-01–09，而非九份互不相关的moodboard。

1. 输入基线：本包版本、产品SHA、截图源SHA；你核对的当前实现与明确不适用的历史材料。
2. 推荐系统：语义、视觉层级、材质、字体、状态、图标、motion的统一规则；关键分歧给少量真正不同的对照和推荐理由。
3. 既往消费账：每条Scout/合同/PR/裁决记 `adopt / adapt / reject / defer`、原因、固定SHA+路径与对本轮方案的影响。改既往裁决必须引用原理由和具体反例。
4. DG-01–09覆盖矩阵：资产/组件/场景、当前能力或sample、状态、来源owner、入口及返回、a11y/静态回退、依赖、许可证与尚缺后端。
5. 交付：原生SVG和构造来源，组件解剖/合法组合表，motion时间线与中断，明暗/宽窄/长文/失败等前后对照。资产能独立查阅，不依赖Design工具账户才能知道方案内容。
6. 验证：区分实际执行、源码推断、未验。不得用“全部通过”覆盖未操作的VoiceOver/IME/forced-colors/真实200%缩放。
7. 建议PR顺序与明确待裁分歧。不得提前声称Astra已接受、合流或产品门关闭。
