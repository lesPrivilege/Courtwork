# 纸墨谱 · 技能执行本

一种设计语言，数张纸。语法（版）恒定，取值（纸墨）可换；换纸零组件分支。本文件自足，可直接执行；权威副本与完整著录在 `deswrit-kit/04-纸墨谱/`（法理见 `03-刊例.md`）。

## 分工

- 本技能治 **UI 视觉层**：色、字、线、记号、密度、器物刻法。
- UX（流程、信息架构、交互模式）从专门的 Design skill；二者叠加使用。
- 中文文案从 fanli 凡例；门禁与验收程序从刊例。

## 三、色律

- 文档面二声部：**朱**司人裁与交互（链接、焦点、批点、不可逆确认）；**雌黄**司校改（错误、警示、涂乙）。主操作用墨；装饰零彩。
- 工作台扩编在场时分轨：**记号色古、交互色今**——朱归裁定印记，交互从 `--jiao`；状态从危/慎/成/中。雌黄与 `--shen` 同声不双用。
- 纸三层（纸→副纸→浮台）代影承面之层级；数据容器取浮台＋界线。**器物另有四阶**（下文五），不与面层混用。
- **二声部不同族**：墨入金族之纸（磁青），雌黄须离金就柠；二声部与墨、二声部相互须色相可辨。
- **暗纸光晕补正**：暗纸上浅字泛光，须字大一分（+2–3%）、行距微开、`--shu` 0.01–0.015em，行长收一字；补正入行款著录语。
- tint（`-di` 淡底）只上小块提示，不作行/卡底；灰字不压彩底；各纸对比度各自复核（文墨对纸 ≥7:1，余 ≥4.5:1）。

## 五、器面四阶（馒版之阶）

底纸居一极（最浅或最深）；器物底向反方递进四阶：`--qi-mian`（常）→ `--qi-fu`（悬）→ `--qi-an`（按）→ `--qi-xuan`（选）。据：套印与馒版——多版分印，每版一次印色，深浅成阶而不靠投影；暗面之层级因此从递亮而得，不从光与影。

- 四阶只承器物（按钮、输入、行、签、开关），不得作面底与卡底。
- 一器一阶，不得跳阶；相邻阶亮差宜 2–4%，可辨而不宏。
- 主按钮不入四阶：墨底纸字，一书唯此一实底器。
- 阶与次界可共作；影仍零处。
- 禁态别取 `--qi-jin`（不入四阶之递）：禁阶底、淡墨字、框不变，并告知何以不可用；淡墨不兼司禁态。

## 六、形律

- **影零处**（文档面）；扩编之 `--ying-tai` 为唯一例外，只上浮台且应记。
- **圭角零**（上限 2px）；无 pill、无胶囊卡。
- 线唯两档：主界（2px）司版框、编界、牌记框；次界（1px）司行列。**界不取墨**：两档界色皆轻调，墨唯承字与实底器物；黑框围面不得。文武双线唯版框与牌记，内线宽 `--kuang-nei-w` 由印法定。
- 字四轨：题、文、器、数各用其族；相邻题级档差 ≥1.25；`font-synthesis:none`。
- 汉文行长 32–38 字，拉丁 65–75ch；间距唯四档，不得全局等距。
- 数据与表格之区绝对静止；**自动**（页面自作之动）唯入场一次编排，transform / opacity 而止；换纸与语义状态零时硬切；`prefers-reduced-motion` 必从。**随手**不在此禁（见七）。

## 七、随手之动与浮层之材

随手（拖、滑、掉、收）非装饰，乃反馈本身；理路取于现行流体界面之学。

- 按下即应（不待释手），反馈贯全程；随手一比一并守捉点之偏。
- 动可随时截、可反；起值取现值（屏上实值）非目标值；转场中不锁输入。
- 释手交速；以势投程（衰减 0.998）而后吸附，非就近吸附；逾界渐阻（皮筋 0.55）不硬止。
- 弹律二档：`--tan-chang`（1 0.35，无过冲）为常；`--tan-shi`（0.8 0.3）唯承有势之释手；二维分 X/Y 两弹。
- `prefers-reduced-motion` 下随手仍随手（其为反馈），惟去过冲与投程；数据区仍无自动。

**影抄之纸**（`--zhi-ying` + `--ying-mo`）唯予浮于内容之上的导航层：

- 只予工具条、粘性头、底页、菜单、浮钮；不予表、卡、列，不作全屏底；一面一层，不叠。
- 其下内容可滚过，交界以渐隐代硬线；字压影抄者加重一档、微开字疏，压后 ≥4.5:1。
- **底为实、透为增**：默认实色（`prefers-reduced-transparency` 未入 Baseline）；影仍零处——透非影。

## 七乙、手位与靶（公法下限）

- 可点之靶 ≥ `--ba-xiao`（24px，WCAG 2.2 SC 2.5.8 AA）；主操作与触屏宜 ≥ `--ba-zhu`（44px，2.5.5 AAA）；图标器以 padding 达靶。
- 小靶以间距救之（24px 径之圆不相交）；行内链接不在此限。
- 凡拖拽（滑块、重排、看板、平移、轮播）必备单指替代：轨可点、上下移按钮、「移至…」菜单、前后翻钮（SC 2.5.7）；手绘与签名为例外。键盘路径不代单指替代。

## 七丙、器上文之语

取材、用色、视觉元素从版本学；**器上文从现代平易汉语**，二者不相涉。古典词汇只行于谱内（槽名、记号名、文档、牌记、著录语）；用户所见之字一律直、短、具体——该写「保存」不写「写定」，该写「删除」不写「黜落」。以古语作按钮即牛附穿凿；陈义之责在形与法，不在词。中文文案另从《撰写凡例》。

## 七、档位

视觉激进度与裁决距离成反比（入藏实证）：激进档（展示叙事面，表达自由最大）→ 中间档（导航 chrome，克制作者性）→ 克制档（数据裁决面，版式从数据生长，零新装饰）。许可不跨档继承；激进档成熟形须过克制审计方可下迁。

## 九、器物刻法（UI 原子）

- **主按钮** 墨底、纸字、直角、无影（不入四阶，全书唯此实底）；hover 仅 opacity .92；高 ≥`--ba-zhu`。
- **次按钮** `--qi-mian` 底 + 次界框 + 墨字；hover `--qi-fu`，active `--qi-an`。暗纸下此三阶即分层之所在。
- **幽按钮** 透明底无框；hover `--qi-mian`。
- **危操作** 朱框或朱字（人裁之痕）；不作朱大底。
- **输入** `--qi-mian` 底、次界框、直角；focus 朱 outline（扩编在场从 --jiao）；错误态雌黄框 + 一句 + 下一步。
- **表格** 表头副纸底 + 主界下线；行分次界；hover 行 `--qi-fu`，选中行 `--qi-xuan`；数字右齐取数轨；数据容器浮台；表区零动效。
- **开关 / 分段器** 槽底 `--qi-mian`，当选项墨底纸字（或 `--qi-xuan`）；零滑入动画。
- **标签** 签条式：直角窄框、器轨小号；不彩虹、不 pill。
- **分组** 间距 + 小题 + 次界线；容器层级由框型与纸三层，不卡中卡、不叠影。
- **解释注** 夹注或眉批，回到页面本身；不浮卡。
- **空态** 淡墨一句 + 下一步动作；不插画。
- **加载** 墨钉块或淡墨 opacity 脉动；不彩色转圈。
- 空态、错误态、加载态、溢出态、禁态、焦点环、键盘路径、单指替代俱备；脱者不得行世。凡器高 ≥`--ba-xiao`。

## 十、著录词（牌记用）

初刻＝初版；重刻＝改版重构；覆刻＝忠实移植；影刻＝登记副本（署非权威）；递修＝增量修订；百衲＝多源拼合须著各源。稿本：手稿＝工作稿；清稿＝净本待雠。書品：上／中／下（审书状产出，下品不得行世）。

## 十一、讳（不得）

国讳从刊例第廿三条：紫蓝渐变、渐变文字、玻璃拟态、三等分 icon 卡、卡中卡、bounce/elastic、animate width/height、01/02/03 脚手架与重复大写 kicker、空话文案、lorem 与假数据、Inter 系独占主字。家讳：影（扩编唯一影除外，应记）、圆角、纸纹贴图、暖黄纸底（退役黑名单）、blackletter、Instrument Serif 代 Garamond、暗面霓虹 glow、tint 作行卡底、灰字压彩底、影抄叠影抄、以透为基线、靶小于二十四、拖拽无单指替代、以古语作器上文。他处借形须一句写据。

## 十二、执行次序

1. 选纸与印法（一之表）；贴底本块入项目 tokens 文件，`yinfa` 与扩编块在后。
2. 页骨架：卷端题名 → 正文列（`--measure` 居中）→ 页侧批注栏（可省）→ 牌记。版框可用文武双线。
3. 以器物刻法落组件；全程 `var(--…)`；工作台面按档位定克制度。
4. 交付前自检：影零（或唯一影已记）？圭角零？彩守声部？线止两档？阶只承器物？靶不下二十四？拖拽有单指替代？器上文全为现代汉语？行款语能一句著录？牌记在？
5. 完整验收从 `05-审书状.md` 叠加刊例附录乙。
