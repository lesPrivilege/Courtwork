**谱名** `zhimopu` · 属 `deswrit-kit`
**定稿** 2026-07-25 · **本** v1.0
**性质** 取值层 · 可离线自足 · 供一般项目采用的设计语言集

## 一、本谱何为

《刊例》治法而不携值。项目采用九步之中，立宗、选善本、立底本、定行款四步向须自作；本谱把这四步做成可直接采用的成品：一套共用语法（**版**），数套各自自足的设计语言（**宗**）。

宗者，一个古典文献形态的现代移译。每宗自足：宗语、据（善本三义著录）、底本（tokens）、行款著录语、家讳俱全，互不依赖。项目采一宗，九步收缩为可填的少数槽位（见 `03-采用模板.md`）。

**位阶**：本谱居《刊例》之下，为判例与取值之层。条文冲突时从刊例；本谱不增删刊例条文。刊例第廿五条（讳表流转）对本谱同样有效：任一宗之形一旦入分布中位，即候补入讳，谱应岁修。

**架构一句话：版通而纸异。** 语义槽、界行、器面四阶、记号、动静之律为版，诸宗共守；色、字、量、行款语为纸，各宗自取。同一产物换宗，只在底本层换值，组件与版式零分支（刊例第五条）。

**一条界限**：取材、用色、视觉元素以版本之学取代当下之路径依赖；**器上文一律现代平易汉语**。古典词汇只行于谱内命名与文档，不入用户所见之字（`01-版.md` · 十五）。

**作为技能引用**：他项目加载 `SKILL.md` 一件即得全语言（UI 视觉层）；UX 从专门的 Design skill，文字从 fanli，法理与门禁从刊例。引用取指针，不整册抄入。

## 五、拒收记

按刊例「拒有记」（第廿九、卅五条），候补形态不立宗的理由与复议门同档记载：

| 形态 | 不立之由 | 复议门 |
|---|---|---|
| 卷子（写本长卷） | 与既有浅纸近纸近墨，所增唯「连续无叶」一义，而网页本已连续滚读 | 项目以连续为宗且分叶为病，判例三见 |
| 经折 | 折面即分屏，义在幻灯类产出；本谱首批以文档为的 | 幻灯 / 分屏产出立例之日 |
| 贝叶 | 窄长叶与穿孔为其全部形义，移译面窄，近于猎奇 | 有真实窄条数据行场景且证得今义 |
| 藏印（裁定链印记） | 义可证而门禁未立，恐沦为装饰徽章 | 与验收流程对接的判例三见 |
| 叶次 · 書口（分页之记） | 書口律已承收合露题一义；分页另立恐一形二义 | 有真实长表分页场景且证得非書口律所能承 |
| 档案（文书反乌托邦） | 试染中：danganshen（深）入样张候目验；浅卡其已退役（见退役账） | 目验后立宗或黜 |
| 反乌托邦之霓虹路 | 撞国讳（霓虹 glow、dark-cyan）且语料已吃透，皮肤而非语言 | 黜，不复议 |
| 拱花（无色浮凸） | 即影，犯影零处之家法 | 影零处废止之日 |
| 包角 | 护角无今义 | 黜，不复议 |

拒收非黜落：复议门开即立宗增补。
