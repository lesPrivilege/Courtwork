### agentMessage · 34ace544-f449-4353-b7f6-38920ab30304

可以把这一轮直接裁成一个很明确的目标：

> **Anthropic 的 publishing grammar，Courtwork 的 visual genome。**

读者第一眼应该产生“这很像某家 Frontier Lab 正式发布的一篇 Research / Engineering paper”的熟悉感；再看第二眼，颜色、材料、插画和局部细节却完全不是 Anthropic，而是 Courtwork 那套冷灰、铅白、石墨、克制甚至略带反乌托邦感的世界。

### 1. 相似的部分应该做到很像

Anthropic 近年的 Research / Engineering 长文其实已经形成很稳定的出版语法：非常轻的站点 chrome，大标题与短摘要先建立论点，日期/作者/论文链接退到次级；一张承担“封面”作用的 editorial illustration 或概念图；随后迅速收窄到阅读列。正文主要依赖排印、留白、hairline、图注与宽幅 figure，而不是 card system。它的研究文章还经常允许图表突破正文 measure，形成“窄正文 → 宽 figure → 窄正文”的呼吸。比如 [Automated researchers](https://www.anthropic.com/research/automated-researchers-mitigate-alignment-failures)、[Global workspace](https://www.anthropic.com/research/global-workspace)、[Multi-agent research system](https://www.anthropic.com/engineering/multi-agent-research-system) 都适合作为 archetype。

所以我会把 Paper 首页从现在这种“预印本 reader”进一步推成：

**masthead → publication metadata → giant title/dek → hero illustration → abstract/key proposition → article**

而不是先出现一排 Reader 控件。

正文依然维持大约 **68–72ch**。这其实与 Courtwork Pages 已经确定的 `68ch` 阅读尺度非常接近；现有 Pages 也明确是“站点拥有自己的阅读尺度，但色彩从产品 token 读取”。

### 2. 陌生化不需要重新发明颜色，Dystopia 已经够强

现在 Courtwork 甚至已经把这套东西写成了真正的 skin。Dystopia light 的几个核心值非常适合直接做 Anthropic publishing grammar 的异化映射：

- Anthropic warm ivory → Courtwork `paper #edf1f3`
- Anthropic near-black → `graphite #242d33`
- 更白的 editorial cutout → `float #f9fbfc`
- 外围冷灰场 → `frame #dbe2e6`
- secondary ink → `#54616a`
- 需要最强黑度时 → `#172025`

而 dark counterpart 已经是 `#151c21 / #202b32 / #2a363e / #e4ebef`。

这比“给 Anthropic 换成蓝灰色”要高级得多，因为 Courtwork 本身已有 **frame → panel → float** 的材料层级，以及稳定的 role token。

所以 Paper 不应该硬编码第二套颜色。更理想的是：

**Anthropic layout grammar**
×
**Courtwork semantic tokens**
×
**Paper-specific typography / reading rhythm**

这样未来产品、Pages、Paper 是同一基因的不同表达，而不是三个长得相似的主题。

### 3. 语言、Canonical / Practice / Index 保留，但降格成“出版工具”

你刚补充的这一点很关键。现有 reader 的能力不能删：中文/English、Canonical / Practice / Index、theme 等确实对真实读者有用；当前发布规范本来也要求三个文本责任保持独立。

但它们不应该再表现成一排显眼的 Web App segmented controls。

更适合 Anthropic 式处理：

```text
Schema Engineering                         2026-09-11

Canonical     Practice     Practice Index
中文 / English                           GitHub ↗
────────────────────────────────────────────────

Schema Engineering

Governing agentic work through
stable, reviewable state.

[dek / abstract lead]

                [editorial illustration]
```

桌面端这些 reader controls 可以是一条极薄的 publication utility rail。选中态主要靠 **ink、underline 或 1px rule**，最多极轻 surface shift；不要 pill 群、不要彩色 active tab、不要明显 button chrome。

移动端再把它们收进一个很小的 `Read · 中文` / `Read · English` 控件即可。

换言之：**功能继续存在，UI 存在感减少。**

### 4. 插画这次已经找到几乎就是你说的那个 Skill

这轮 Exa 找到了非常准确的社区实现：

[HalfAI1102/anthropic-art](https://github.com/HalfAI1102/anthropic-art)

它明确就是一个 **Anthropic-style editorial illustration Agent Skill**，而不是普通 diagram skill。作者甚至基于 Anthropic Newsroom、公开 SVG 与 CSS 去反推它的视觉规则。核心结构是：

**满版柔和背景 → 55–80% 不规则浅色承载形 → 粗、轻微抖动的近黑手绘线条**

并且主动禁止渐变、shadow、3D、摄影感和 generic corporate vector。

这个比前面找到的 `anthropic-style-diagram` 更适合 **Paper hero**；后者仍然适合正文里的结构图。

但这里不应该直接使用它原有的 Anthropic palette。可以直接 fork 成一个很小的：

**`courtwork-editorial-art` / `se-editorial-art`**

只保留它的 composition grammar：

```text
full-bleed field
irregular carrier shape
heavy hand-drawn graphite line
one visual metaphor
no text
no gradient
no shadow
deliberate asymmetry
```

再把 palette 全部替换为 Courtwork Dystopia tokens。

这样生成出来的东西会很有意思：**构图机制明显让人联想到 Frontier Lab research publishing，但那种暖象牙、陶土橙、浅绿色会全部消失，变成冰冷的灰蓝空气、石墨线和近乎实验室档案纸的承载面。**

这正是你说的“非常像，但完全陌生化”。

### 5. Hero 插画的题材也不应该只是画 Schema

第一张图甚至不建议画常规 `State → Context → Proposal → Commit` 流程图。那应该留给正文 figure。

Hero 更适合从 Paper 最核心的 tension 中抽一个**视觉隐喻**：

> 一台概率性的、不断运动的机器在左侧吐出大量不稳定形态；中间经过一条极窄、带审阅痕迹的“commitment aperture”；右侧只留下少量坚硬、可堆叠、带来源刻痕的对象。

或者：

> 一个巨大的连续工作结构横跨画面，一个小型模型/执行者从结构中被拔出替换，但结构本身不坍塌。

后者尤其适合一句：

**The model can leave. The work remains.**

而且比画一个数据库、Agent box、箭头流更像真正的 editorial illustration。

---

因此我会把这一轮的设计裁决写成一句非常短的 Design Brief：

> **SE Paper · 2026-09-11**  
> Rebuild the publication surface using Anthropic Research’s editorial grammar, not its brand. Preserve Courtwork’s Dystopia token system as the sole visual source. Retain Canonical / Practice / Index and bilingual reading controls as quiet publication utilities. Introduce one original hero illustration generated through a forked `anthropic-art` workflow, replacing Anthropic’s warm palette with Courtwork cold-ash / graphite materials.

当前旧 reader 的确仍然是独立的一套冷白/灰蓝 token，并带有明显 reader toolbar/card chrome，正好可以作为这轮要被淘汰的 baseline。

另外，**2026-09-11** 我建议直接作为这一版对外 publication surface 的定版日期；如果 Canonical 文本本身仍保留独立版本号，则让两者并列，而不要偷偷把 UI revision 冒充成论文内容版本。这样版本链最干净。
