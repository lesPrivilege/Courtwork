# EX-GI1 identity specimen

This directory is a read-only visual specimen for the EX-GI1 generative-identity exploration. [`index.html`](index.html) presents three static SVG directions (`direction-a.svg`, `direction-b.svg`, `direction-c.svg`) using the same stated content and invariant geometry. The page itself says that no direction has been adopted.

The underlying exploration note is [`ex-gi1-generative-identity.md`](../../mvp/execution/work-surface-kit/explore/ex-gi1-generative-identity.md). This folder is design input only: it does not define the runtime brand package, change application UI, or establish a chosen identity. For the current standalone brand owner, read [`brand/README.md`](../../../brand/README.md).
