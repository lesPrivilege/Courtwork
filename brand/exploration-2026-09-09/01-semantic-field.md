# 01 · 语义场（Fable，2026-09-09）

mark 是第 1 层几何要回答的问题："CourtWork 长什么样"。回答由它必须表达与不得表达的语义限定；材质与运动不参与这一层。

## 必须表达（四个，按权重）

| 语义 | 几何上的可能载体 | 为什么 |
|---|---|---|
| **记录 / 文书**（record, document） | 一块有边界的平面；平面上的秩序（行、栏、边距） | 产品的对象是 Matter、Artifact、来源与决定，不是对话 |
| **治理 / 约束**（governed, framed） | 闭合或将闭合的框；对齐的边；被压住的一角 | Paper 的核心：候选只有经验证与裁定才生效 |
| **状态与版本**（prior state, version） | 错层；第二个更小的平面露出一角；一段偏移 | Matter 跨时间存在；当前版本之下有先前状态 |
| **审阅与来源**（review, provenance） | 一条不被主体覆盖的侧边 trace；一个极小的校勘符号 | Review 是一等表面；事件日志不可擦除 |

四者不必全部同时出现；一个方向可以以一两项为主，但主语义必须是前两项之一。

## 不得表达

- 法律 cliché：法槌、天平、法院柱廊、盾徽、书本轮廓、卷轴。
- AI cliché：星芒 sparkle、对话气泡、脑 / 芯片、渐变光球、"魔杖"。
- 创业 SaaS 惯性：字母组合 monogram、几何抽象的无语义多边形、随机圆角 blob。
- 微型文字、渐变、玻璃、模糊、三层以上叠加。

## 与现有母题的关系

现有母题（竖 stem + 长 / 长 / 短三行）表达"记录的行"与"在场的竖线"，语义落在第一项，偏"清单 / 列表"，与 Chat UI 的行列易混；治理、版本与来源三项没有载体。它作为 E · Record lines 同台比较，不作母版。

## 判据（选向时用）

1. 16px 黑白剪影能否与 Finder 侧栏、Lucide 邻居区分（身份）。
2. 不解释时，看得出"文书、治理、状态、审阅"中的至少两项吗（语义）。
3. 放大到 64 后是否仍无需材质就成立（耐久）。
4. 会不会被读成法律软件或 AI 助手（安静 / 陌生化）。
5. 第 3 层能否从它出发做 base → state → base 而不改几何（可扩展）。
