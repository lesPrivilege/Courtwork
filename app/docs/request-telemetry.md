# Model effort and request measurements

RuntimeStore7 adds optional provider `reasoningEffort`: off/minimal/low/medium/high/xhigh/max. Provider configuration rejects a level outside the installed model's `getSupportedThinkingLevels` map; admission rechecks it. The descriptor is frozen on each Run and passed to Pi `createAgentSession({thinkingLevel})`. Omission retains SDK default/resume behavior; request events record actual effective effort. Catalog responses include supportedEfforts/defaultEffort. No endpoint test or credential inference follows selection. Configuration remains host-global and frozen during any active Run.

Schema3/4/5/6 is fully validated against its old shape before an exact byte backup and atomic migration. Existing project/global Session scopes and async tasks are preserved. Old hosts reject7. No running personal data directory is part of verification.

`runtime.request.telemetry` v1 events are emitted at the host streamFunction boundary, using a monotonic elapsed clock and separate wall-clock start/end. Identity is Run + requestId; purpose distinguishes agent from compaction. Phase is started, streaming, completed, cancelled, failed or interrupted. Multiple observations replace the same request only in a read projection. Event persistence uses the existing awaited drain; no second model loop or transcript owner is introduced.

firstOutputMs is dispatch-to-first nonempty thinking/text/toolcall delta observed by the host; firstTextMs uses text only. These include transport/adapter work and are not provider TTFT. decodeTokensPerSecond and providerTtftMs remain null because the current SDK provides no provider token clock or timestamped token counts. No output/Run-duration or character-rate proxy is labelled TPS.

Request context records serialized-request UTF-16 character count and ceil(chars/4), explicitly heuristic. It covers system text, messages and tool declarations passed to this request, not the exact provider encoding, tokenizer or remaining capacity. No context text is copied into the measurement event. Context window is declared catalog capacity. Terminal usage has independent nullable input/output/cacheRead/cacheWrite values; failed/interrupted requests have no successful-usage assertion. Requested and observed model identity are separate. No inferred cache ratio or billing.

The shared model picker serves Chat and Attention. Native modal/select semantics, searchable catalog, declared effort options, explicit global-save label, empty-search save prevention and draft/focus preservation are retained. Closing a submitted save does not revoke it; parent state still receives the saved configuration. Attention's composer stays one line. In-place details show the last request; Inspector shows retained per-request history. Malformed measurements fail closed in the renderer.
