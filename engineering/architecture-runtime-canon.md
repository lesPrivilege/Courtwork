## 2026-09-19 · Local Agent Orchestra direction

[The Local Agent Orchestra ruling and evidence](research/architecture-node-2026-09-13/orchestra-direction-20260919.md) continue the five-layer architecture: Orchestra is a composition direction, not a sixth layer or second ledger. The reference harness reuses the Pi loop; Host owns admission, binding, effect/receipt, recovery, and cross-Runtime delegation; Local and Hosted executors meet the same minimum Port obligations. Role, Kit, Agent Instance, ExpertDefinition/Instance, Runtime, Provider, Model, and Environment remain separate. This is a documentation registration; Kit schema, hosted lane, Spark/Attention composition, and the complete loop are not accepted.
