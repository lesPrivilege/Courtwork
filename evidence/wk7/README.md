# WK7 color and contrast evidence

This packet records the WK7 computed-color and contrast measurements. [`computed.md`](computed.md) contains the browser-computed values and overflow observations for the named viewport/theme cases; [`contrast.md`](contrast.md) contains the WCAG 2.x relative-luminance table and the local thresholds used by the check.

The packet is a static color/contrast measurement slice. It does not by itself establish full visual, browser, accessibility, touch, desktop-shell or product acceptance, and the computed report records any paths that were not exercised. Current product status remains [`engineering/current.md`](../../engineering/current.md).
