- effect vocabulary: current-rule | reference | intake-open | intake-closed | history | superseded (with target) | unknown. Where a package mixes states, both are written. Nothing is marked closed unless its own text or a named later record says so; otherwise `unknown`.

Computed by grep of the directory name (research) or the exact `design/<name>` path form (design), then hand-checked. `-` means none of the four; the package may still be linked from other docs (named in `consumption`). Research dirs sharing a name with a design twin (agent-presence-2026-09-11, developer-control-panel-2026-09-13, chat-reading-2026-09-11) can show C for either.
- material types: extension counts (md, json, png, ...). "handwritten md" is every md not in a raw input path; raw/API returns are flagged in `disclosure`.
- disclosure (flags only, no judgment): `/Users x N` = lines containing `/Users/`; `tmp/~ paths x N` = lines with /private/tmp, /tmp/, ~/Projects, ~/.codex etc.; `Downloads x N` = lines containing "Downloads" (often benign prose or vendor doc text); `RAW n files` = raw web-chat/API returns or verbatim pasted inputs (conversation.json, connector-response, input-snapshot, inputs/, ...); `chat IDs x N` = distinct chatgpt.com/c/ or chatgpt-conversation:// identifiers cited in text.
