# HC-01-B · Agent capability compatibility index

**As of:** 2026-09-08. **CourtWork source:** `429fdd68febb9998f322a0b53c323651fc8cd7fd` (temporary execution tree `codex/luna-maintenance-core-validation`). **Scope:** source inspection plus the existing local/loopback test evidence named below. This is a capability and integration index, not an acceptance of the product, Paper, legal quality, or a real provider.

The decisive distinction is **upstream capability ≠ host exposure**. CourtWork pins `@earendil-works/pi-coding-agent`/`pi-ai` v0.85.1 at `d981de1229ef899957bbe968bc8dcda02a21f477`; it embeds one `AgentSession` per Run against a persistent Pi `SessionManager`. Pi owns the model/tool loop, JSONL journal, retry and native summary. RuntimeService owns command admission, the host store, permission questions, workspace tools, event projection, configuration, and recovery. A UI switch, a type declaration, or a dependency API is not evidence that the host exposes the capability.

## Status vocabulary and evidence rules

| Status | Meaning in this index |
| --- | --- |
| `native` | CourtWork itself owns the behavior and has a source/contract and test or route evidence. |
| `adapter` | CourtWork maps a host contract to Pi or a southbound protocol; the mapped subset is evidenced. |
| `fallback` | A real alternative product entry point or explicit degradation path that can serve the capability when the primary path is unavailable. A test fake does not qualify. |
| `intentionally unsupported` | The current contract explicitly excludes the capability (for example, a published `false` capability or a documented boundary). |
| `absent` | No current owner, persisted field, route, or GUI entry was found in the inspected host. It may be a future slice. |
| `unverified` | A source or upstream description was found, but this host's behavior or a required version/transport detail was not verified. |

`native` and `adapter` are deliberately scoped to the host, not to Pi. `intentionally unsupported` is used only where the current source or contract says so; a missing search hit is `absent`. “Import/export” below means a supported path for the capability's facts, not copying private credential stores or silently importing a second source of truth.

`validation: test-only` is a separate evidence dimension for deterministic fake or scripted fixtures used only by tests. It does not promote a capability to `native`, `adapter`, or `fallback`, and it is not a product entry point or degradation path.

### ACP naming note

This index uses **ACP = Agent Client Protocol** (`agentclientprotocol/agent-client-protocol`), the editor/agent JSON-RPC protocol, because that is the relevant northbound agent UI boundary. A separate project uses the name **Agent Control Protocol** at [acp-protocol.org](https://acp-protocol.org/) and [its GitHub spec](https://github.com/agent-control-protocol/acp/blob/main/spec/SPEC.md); CourtWork has no implementation of either. The two must not be conflated when a future compatibility slice is scoped.
