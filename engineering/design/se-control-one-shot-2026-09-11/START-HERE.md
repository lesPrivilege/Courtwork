# 提交给独立 Design 的一次完整任务

请为 Courtwork 提交一次系统性 Design：以 Spark / Attention 的原生图标和连续控制面表达 SE 对持续工作的治理，并统一 Chat Space、composer/thinking/streaming、Explore agent协作、Settings/tab/tap、发布面与 Visual Grammar。请完成推荐系统、关键对照、原生资产、状态/动作/动效矩阵及既往裁决消费账，不只返回单张概念图。

阅读按渐进披露进行：

1. [HANDOFF](HANDOFF.md)：问题、固定产品与媒体版本、范围、能力和返回边界。
2. [Scout摘要 L0](scout-digest.md)：先把握九条结论，按本轮场景展开L1；有分歧才追L2原文。历史角色/待办不自动恢复。
3. [决策索引](decision-index.md)与[DG-01–09提案](proposals.md)：逐项消费既往裁决、PR、真实实现与缺口。截图中的两个相邻panel-right也在此。
4. [Taste Memory](taste-memory.md)：保留上下文、被拒方案、理由和不确定；不设总审美分数，不虚构用户比较结果。
5. [返回合同](RETURN.md)：统一返回可裁决、可复现的方案。Astra收到后逐项adopt/adapt/reject/defer，再拆施工并合流。
