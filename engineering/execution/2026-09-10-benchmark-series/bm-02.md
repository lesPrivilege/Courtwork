# BM-02 · Bind Continuity runs to a reproducible evidence manifest

## PR body

Current Continuity outputs already preserve attempts and a journal; a family-wide manifest will make source custody and report regeneration explicit.

Add versioned JSON schemas for scenario, observation envelope, receipt and manifest. Wrap existing output without changing observation v2 semantics. Record requested/resolved inputs, content digests, environment, seed and all attempts. Add deterministic report generation and sealing.

## Validation

Reject missing or tampered raw files, duplicate attempt IDs, changed oracle, dirty-source mismatch and interrupted seals. Rebuild identical report bytes from sealed records; retain failed attempts. Rerun existing grader negative controls.

## Scope and dependencies

Benchmark tooling only. No product schema change. Preserve old evidence bytes.

BM-01 accepted contract; independently reviewed schema and digest ordering.
