## Review dispositions

| Finding | Disposition | Landing |
|---|---|---|
| 1 · a chat switch mid-batch kept sending later files to the old chat | **Adopt**: the batch checks its chat before each file; later files are reported "not sent" | `materials-view.mjs` addFiles; test with mutation check |
| 2 · a finished batch reported in the next chat's popover; an empty result read "Saved 0 files" | **Adopt**: a batch belongs to the chat it started in; if that chat was left, a toast reports it and the new chat's popover stays empty | `chat-files-attach.mjs`; test with mutation check |
| 3 · light dismiss during a save lost unresolved outcomes and their Retry | **Adopt**: a closed popover reports by toast, and unresolved outcomes stay until the popover is opened again | `chat-files-attach.mjs`; test |
| 4 · Retry destroyed the focused button; status stale after a retry | **Adopt**: focus moves to the status while busy and back to the file input after; the status is recomputed after a retry | `chat-files-attach.mjs`; test; browser |
| 5 · a refresh failure left a stale error in the Files dialog | **Adopt**: the next good refresh clears an error that came from a refresh | `materials-view.mjs` |
| 6 · list not refreshed before saving; `uploadId()` failure lost earlier outcomes | **Adopt** the per-file `uploadId()` guard; **reject** a forced refresh: a stale revision is refused by the Host as a conflict and reported | `materials-view.mjs` |
| 7 · pressing the paperclip while open reopened the popover | **Adopt**: a press while open closes it | `chat-files-attach.mjs`; test |
| 8 · dead `renderRequestMeasurements` import | **Adopt** (removed); the unused `providerLabels` import predates this slice and is left to its owner | `app.mjs` |
| 9 · tests covered only the happy path | **Adopt**: superseded, conflict, link failure with same-command retry, unknown, oversize, partial coverage, chat switch, popover ownership | tests |
