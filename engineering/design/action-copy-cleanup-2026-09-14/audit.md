# Action-copy cleanup audit · 2026-09-14

Bounded review of the composer workspace entry, Home module footer, model-picker entry, and Settings cross-links. I inspected the pre-cleanup captures [01 composer](evidence/01-composer.png), [02 workspace menu](evidence/02-workspace-menu.png), and [03 Models](evidence/03-models-before.png), plus the current source. The shared source already contains the author’s proposed copy edits; this table records the non-author recommendations against the original wording. Later author captures are not an independent visual or product acceptance.

| Original → recommendation | Location and text role | Behavior / security effect |
|---|---|---|
| `Choose workspace` → `Workspace` | Composer trigger: [index.html](../../../app/web/index.html#L337) and its dynamic text, title, and empty-state accessible name in [app.mjs](../../../app/web/app.mjs#L5138). Visible button, hover title, and button name should agree. Keep a non-empty accessible name on the popover dialog (`Workspace` is sufficient); its `No workspace` and `New project` choices retain state/create context. | Same popover and optional workspace binding; no permission or routing change. |
| `Manage connections` → `Connections` | Home module footer button: [home-view.mjs](../../../app/web/home-view.mjs#L309); visible text is also its accessible name. It routes to Settings › Models. The band has no visible `Models` heading beside this button in capture 01, so the destination noun is enough. This intentionally supersedes the older local wording rule in [copy-convention.md §3.5b](../copy-convention.md#35b-home-的次级模块带-cc-d0-a--wk-114--wk-117-b). | Same Settings destination; no connection is changed merely by following the button. |
| `Choose model & effort` → `Model & effort` | Connection card entry: [settings-view.mjs](../../../app/web/settings-view.mjs#L453). Visible action; the shared action control uses the same string as its accessible name. It opens the model/effort picker rather than saving a selection. | Same picker. Keep the actual `Save and ask once` / `Save only` action labels and their distinct send behavior. |
| `Manage tools` → `Tools`; `Review permissions` / `Manage permissions` → `Permissions`; `Inspect runtime` / `Open Developer` → `Developer` | Visible Settings links in [runtime-view.mjs](../../../app/web/runtime-view.mjs#L2100) and [runtime-view.mjs](../../../app/web/runtime-view.mjs#L2401). The link text is also its accessible name; the labels describe the destination groups, and their `href`s remain unchanged. Capture 03 shows the Runtime adapter links before cleanup; the Plugin cross-links were source-reviewed only. | Navigation only. No policy, tool exposure, runtime, or host behavior changes. |

Keep action wording when it names an actual operation or supplies needed context: `Inspect this run` is the accessible name/tooltip for an icon-only run-detail button ([app.mjs](../../../app/web/app.mjs#L3197)); `Edit connection` and `Change connection` remain distinct actions; `Choose a model to draft a change` and `Select an installed model` are selection guidance, not destination labels. The cleanup is copy-only and does not imply a change to service or authorization semantics.
