# F3 / G1–G4 · 最后真实探针与演示准备

此为待执行配方。先通过新候选产品检查，再由用户在独立GUI配置自己的已授权连接；不从其他实例读取/复制key，不在聊天、日志或证据导出key。Provider身份、model、API/endpoint、config revision、declared reasoning与实际省略/发送字段分开记录。预算是请求/turn与wall-clock边界，不冒称货币预算。

## 有界真实探针

沿现有Pi与同一合成Project Cedar，CLI启动时使用`--max-turns 8 --deadline-ms 180000 --compaction-limit 0`；每个目标只执行一次，失败保留原回执，不无限重试。最多6个Run，加GUI显式的一次连接检查；合计最多48个普通agent turn与一次连接测试；这不是HTTP传输次数硬上限，adapter传输重试另计实际attempts。每Run最多8个普通turn。真实返回较少时记录实际数；工具错误或需要用户输入不会被剪成成功。取消执行计时不包括人等候，与CLI合同一致。

1. 默认参数普通回复；核对Provider配置、实际response和终态。
2. 单个合成`ws_write`请求：在GUI精确Deny，检查未写入。工具拒绝不等于整个Run失败，保留模型后续响应。
3. 独立写入请求：核对路径/内容后Approve，随后读取相同文件；保留实际hash、调用与批准事件。
4. 发起一个可观察运行并主动Cancel，按实际结果记录cancelled/completed竞态。不能因响应过快而声称cancelled；此时该子项记未观察，不自动加Run。
5. 在同一个明确绑定的NDA工作中，用[自然语言流程](../../app/docs/first-work.md)让模型读取source并自行构造/提交domain。不得把buildReview生成的答案塞进模型输入。检查source版本/四条规则/未决/候选；按原GUI作合成正式决定，保留失败原因与人的reason。
6. 正常退出Host并重启，新Session绑定相同Matter，要求模型从正式状态继续并读accepted Artifact；比较来源/成果/未决身份。前一步没有合法候选或未接受时，只验证实际未决状态，不补假成果。

显式effort值仅在该真实连接确证支持时加到一个既有Run（优先第6项），不额外扩模型矩阵。未知/不支持时按合同拒绝或记录未覆盖，不能任意填一个档位求通过。合成P05已证明参数编码与拒绝，但不替代上游实际支持。难稳定诱发的外部故障由明示合成反例补齐，真实NDA成功与否保持原结论。仍缺连接或用户授权时，仅交付这份准备，不触发付费请求。

## 2–4分钟演示顺序（未录制）

- 0:00–0:25：固定源SHA/data kind/模型身份；进入已按GUI配置的合成工作，展示来源和适用范围。不要录入key。
- 0:25–1:10：模型读取来源并执行；展开一次实际工具/来源记录，讲清执行权限。实际等待如需剪辑，明确标出时间跳转。
- 1:10–2:10：打开Work review，核查规则、来源和未决，填写reason并作实际可用决定。失败/未决保留，不替换成脚本成功。
- 2:10–3:10：新Session继续同Matter，展示正式成果/来源/未决与读取，区别历史消息和当前工作。
- 3:10–3:30：给出可复现源码/输入，限定这条已观察路径的范围。
