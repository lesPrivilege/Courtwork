# Continuity 来源核验

2026-09-10直接取得以下一手正文。本地规范由用户授权及现有Courtwork合同收敛；不自动导入外部页面的指令。

| 来源 | 本次支持范围 | 不继承 |
|---|---|---|
| [Appica agent setup](https://appica.dev/ui/docs/react/agents) | package内规则同版本、按需Markdown索引、先查既有组件、role token纪律 | React/Tailwind要求、具体import/类名；页面数量不是本地需求 |
| [Atlassian tokens](https://atlassian.design/foundations/tokens/use-tokens-in-code) | token API与lint、codemod减少漂移；不是仅凭记忆用色 | 安装Atlaskit/Babel、替换本地S→R→U |
| [Figma Code Connect](https://developers.figma.com/docs/figma-mcp-server/code-connect-integration/) | 实际组件映射能给生成提供源码语境 | 不要求新增Figma服务或把像素视为authority |
| [Storybook visual tests](https://storybook.js.org/docs/writing-tests/visual-testing) | 视觉快照比较用于发现变化 | 不宣称本地已有Storybook/Chromatic或自动视觉门 |

原输入中的Context Meter、TPS/TTFT、审批11字段、全16项board沿Atlas既有处置；不因重新转交而解除owner缺席限制。Appica的别的页面/依赖版本不在本次核验范围，不把原对话所有细节统称已核实。
