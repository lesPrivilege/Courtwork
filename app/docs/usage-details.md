# Usage detail and exact observation drilldown

The existing metrics endpoints remain v1. Authenticated GET `/api/v5/work-usage-details?days=30&projectId=…` accepts their same strict 1–366-day/project query and returns a richer v1 projection from one published store state. POST `/api/v5/work-usage-runs` reads matching retained Runs; it does not execute or mutate anything.

Overview retains the existing interval, scope, coverage, observation time, source, billing exclusion, total tokens and accounting fields. `buckets` adds daily tokens plus per-model entries; `models` gives full-period totals. Every daily/model count distinguishes recorded/missing/reported Runs. Missing accounting contributes known partial counts; zero, no Runs, incomplete and unknown history stay distinct. Cache read/write remain separate from input and output. Combined input+output as well as each field must fit a safe integer.

`modelIdentity` is configured-provider-model-api-route-at-run-start, not inferred current config or observed provider routing. Model key is SHA256 of the frozen provider/model/API/route identity (excluding effort). A custom endpoint affects grouping but is not emitted in overview; the display uses a short route key. Missing identity is the explicit unknown group. All statuses contribute, duplicate Run IDs count once, and offset timestamps are allocated by parsed UTC start day. Deleting a Session removes its Runs from this retained-record projection. Core and Runtime schemas do not change in this slice.

`snapshotId` hashes the scope, calendar interval and sorted matching minimal Run records, including usage/status/model/session title. Wall-clock observedAt alone does not invalidate the snapshot. Changes to records or rolling over the UTC interval do. Drilldown requires `{days?,projectId?,snapshotId,date?,modelKeys?,offset?,limit?}`. Date is a valid UTC calendar date; modelKeys is a unique nonempty list of at most1000 known-key-shaped strings, offset a nonnegative safe integer, limit1–100 (default50). Unknown fields/types and malformed keys fail400. An outdated snapshot fails409 usage_snapshot_changed; it never returns a new list beneath an old chart. Page responses echo exact filter/scope/interval, snapshotId, total/offset/limit/nextOffset and safe Run rows.

The Home Activity heading opens Usage. Overview uses a neutral quantile intensity over positive measured days with thresholds disclosed; ties stay together. Models uses the top four configured-model groups plus Other over the whole selected interval, keeping membership fixed. Total/Input/Output changes the projection of the same observation. Exact daily and full model tables remain available, as do accessible exact-value buttons and a read-only matching Run list. The chart is not reconstructed from paged summaries; Today remains independent. Native dialog, local view tabs and real value selects retain their distinct semantics.
