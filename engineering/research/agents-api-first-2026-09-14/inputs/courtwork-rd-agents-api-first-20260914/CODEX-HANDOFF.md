## GUI 合流合同的最低责任

**读面**：同一对象能给出身份/版本、当前状态、来源/coverage、合法动作和未知项。snapshot/delta、上游事件和本地投影各有角色，不在浏览器建立第二份正式状态。

**写面**：动作绑定对象/expected revision/内部请求身份；后端重新验权。错误、CAS 冲突、已受理但结果未知、撤权各有可恢复后果。稳定状态文字不由动画或机器人表情代替。

**运行面**：connection、environment、root turn、child turn、application tool call 和 Work decision 分开；前端只展示真实提供的功能。必要的状态组合由原 owner 定义，不把一个大 enum 塞进所有层。

**生命周期**：关闭 overlay、换页面、停 stream、取消 turn、归档本地会话、删除云 session、释放第三方 compute 都是不同效果；有动作才显示，有回执才声称完成。

**来源与产物**：精确引用和 bytes/hash 可核对；下载不自动 accepted；删除执行器不删除已合法保留的工作。历史输出可只读，不为显示而启动旧代码。

## 浏览器研发循环

用户启动真实 Web UI 后，先确认 origin、build identity、独立数据/profile 与许可范围。检查页面、读源码、局部修改、跑对应测试、重回真实路径。需要真实模型或云环境时，只调用已配置且明确获准的连接，限定合成输入和任务范围。

禁止为通过测试直接把正式 Decision 写进 DB；禁止在受测页面注入模拟完成状态冒充产品。fixture 设置与实际用户路径留两种记录。仅查 DOM 能发现交互问题，无法代替布局/视觉；实际截图也不能代替保存/版本/actor 的反例。

作者检查与非作者接受分列。切片合流后再核对组合，避免“后端验的旧版 + 前端拍的新图”混成一个结果。已做测试按源相关性复用，不机械重复全量，也不省略本片新增的真接缝。

## 停止与升级

出现旧 Run 效果未知、权限无法映射、环境无法隔离、API 关键行为与文档不符时，记录原始反例并停在该能力边界；不自动换到更高权限、不盲重发。保留 Pi 可用路径。

当最小纵切成立，更新原 current/合同/证据和使用说明。Agents API、外部原生 Chat、跨 Runtime 调度、工作区接管仍各有支持范围；不得把一个 lane 接通改写为全部长周期事项已完成。
