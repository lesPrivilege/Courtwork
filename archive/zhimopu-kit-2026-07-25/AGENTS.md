# AGENTS.md — 纸墨谱使用说明

本目录是**纸墨谱**：一套以版本学（古典文献之学）取代当下 AI 界面路径依赖的 UI 设计语言。语法一套（**版**），取值数套（**宗**＝纸），换纸零组件分支。

## 一、最短路径

1. 读 `SKILL.md`（集大成执行本，一件自足）。
2. 从其「二、底本」整块粘贴 tokens 入项目 CSS。
3. 组件内只写 `var(--…)`，零字面量。
4. 交付前过 `05-审书状.md` 谱1–15。

不必读全包。要立项、要长期维护，才读 `01-版.md` 与 `03-采用模板.md`。

## 二、这套语言管什么、不管什么

- **管**：色、字、线、层、器面阶、记号、密度、动效与手势之律、靶尺。
- **不管**：UX（流程、信息架构、交互模式）——从专门的 Design skill；中文文案——从 fanli 凡例；法理与门禁——从上一层《刊例》(`../03-刊例.md`)。

**一条界限（最易犯）**：取材、用色、视觉元素从版本学；**器上文一律现代平易汉语**。古典词汇只行于设计系统内部命名与本包文档，不入用户所见之字——该写「保存」不写「写定」，该写「删除」不写「黜落」。

## 三、选纸

| 纸 | `data-zong` | 何时用 |
|---|---|---|
| 月白 | `yuebai` | **默认**。文档、规范、工作台 |
| 磁青 | `ciqing` | 暗面。与月白为昼夜对，字同纸异 |
| 拉丁 | `ladin` | 拉丁文为主、中西混排 |
| 档案深 | `danganshen` | 试染未立宗，采之须自补据与家讳 |

另有**印法**一轴：`data-yin="gu"`（古印，默认）/ `"jin"`（今印，扁平化）。二轴正交，皆只换值。

退役之纸（`songkan`、`danganqian`，暖黄纸系）**不得加载、不得重用**——存档只为留痕。

## 四、不可破的几条

- 值唯出 tokens；**根值唯一**：只有默认纸与古印得写 `:root`，他纸唯写 `[data-zong=…]`。
- 彩止二声部：`--zhu`（人裁与交互）、`--cihuang`（校改）；主操作用墨，装饰零彩。
- **影零处**；层级以纸三层（`--zhi`→`--zhi-fu`→`--zhi-tai`）与两档界线承之。浮层另有影抄之纸（`--zhi-ying` + `--ying-mo`），一面一层不叠，实色为默认、透为增益。
- 器物自有四阶（常`--qi-mian`／悬`--qi-fu`／按`--qi-an`／选`--qi-xuan`），只承器物不作面底；禁态别取 `--qi-jin`。
- 圭角零；线止主次两档；字四轨（题／文／器／数）各用其族，档差 ≥1.25。
- 数据区绝对静止；自动之动唯入场一次。**随手之动**（拖滑掉）不在此禁，从弹律 `--tan-chang`／`--tan-shi`。
- 靶 ≥`--ba-xiao`(24px)，主操作 ≥`--ba-zhu`(44px)；凡拖拽必备单指替代。
- 记号一记一义，图形唯出 `jihao.svg`；行世产物携牌记（版本、日期、生成器、底本指针）。

| 文件 | 何时读 |

| `04-AGENTS摘编.md` | 贴进你自己项目的 AGENTS.md／CLAUDE.md |

## 六、样张怎么开

`样张.dc.html` 与 `覆盖度审.dc.html` 皆为单文件设计组件，浏览器直开即可（须与同目录 `support.js`、`02-宗谱/`、`jihao.svg` 同在）。样张顶部可切纸与印法，切换零时硬切、markup 不变——此即本语言的核心主张之实证。
